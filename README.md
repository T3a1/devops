# DevOps

DevOps projects from Epitech: CI pipelines, a Jenkins server defined as code,
and the automated deployment of a multi-service application with Ansible.

| Project | Summary | Stack |
|---------|---------|-------|
| [chocolatine](chocolatine) | CI pipeline: coding style, build, tests, then mirroring to another repository | GitHub Actions |
| [mymarvin](mymarvin) | Jenkins server fully configured from code: users, roles and jobs | Docker, Jenkins, JCasC, Job DSL |
| [octopus](octopus) | Deployment of a five-service voting app on virtual machines | Ansible, Ansible Vault, systemd |
